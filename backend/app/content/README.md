# content/ — 아산 향토사 학습 콘텐츠 (백엔드 전용)

이 폴더는 FastAPI 백엔드의 `backend/app/content/`에 그대로 들어갑니다.
**프론트에는 배포하지 않습니다.** `answerIndex`, `fact`가 정답 정보이므로 서버만 읽습니다.

## topics.json — 학습 카드 · 챗봇 근거

| 필드 | 설명 |
|---|---|
| `id` | 주제 식별자 (`onyang`, `maengsaseong`, `yisunsin`, `gongseri`, `seonjang`) |
| `order` | 스테이지 번호 (1~5, 시대순) |
| `title` / `subtitle` / `era` | 화면 표시용 |
| `keywords` | 학습 화면 키워드 칩, 변형 출제 시 참고 |
| `cards[]` | 학습 단계에서 학생이 읽는 카드 (`title`, `body`) — 프론트에 전달 |
| `chatbotContext` | 학습 챗봇·오답 해설 프롬프트에 주입하는 근거 요약 — **서버 전용**, 프론트로 보내지 않음 |

## questions.json — 문제 은행

| 필드 | 설명 |
|---|---|
| `id` | `주제약어-번호` (예: `ony-01`) |
| `topicId` | `topics.json`의 `id` |
| `difficulty` | 1 쉬움 / 2 보통 / 3 어려움 — 웨이브 진행에 따라 서버가 골라 출제 |
| `stem` | 문제 |
| `options[4]` | 보기. **작성 편의상 정답은 항상 0번** — 서버가 출제 시마다 순서를 섞고, 섞인 정답 위치를 세션에 기록 |
| `answerIndex` | 원본 배열 기준 정답 위치 (현재 모두 0) — 서버 전용 |
| `fact` | 정답의 근거가 되는 한 문장 — Gemini 변형 출제 시 "이 사실을 바꾸지 말 것"으로 고정하는 앵커, 서버 전용 |
| `explanation` | 게임 종료 후 오답 정리 화면과 정답 피드백에 사용 |
| `source` | 출처 자료 파일명 (검수용) |

## Gemini 변형 출제 규칙 (1-b에서 구현)

1. 게임 시작 전, 해당 스테이지 문제마다 `fact` + 정답 텍스트를 고정하고 `stem`과 오답 보기 3개만 새로 쓰게 함
2. 스키마 검증: 보기 4개, 정답 텍스트 포함, 보기 중복 없음, 초등 눈높이(문장 60자 이내)
3. 검증 통과분만 `question_cache`에 저장, 실패 시 원본 문제로 대체
4. 현재 학습 카드에 없는 사실은 문제로 만들지 않도록 프롬프트에 `chatbotContext`를 함께 제공
